# Your Font Files

Drop your custom font files here (OTF or TTF format).

If you don't have custom fonts, that's completely fine. Use system fonts like Arial, Georgia, or Trebuchet MS in your brand.yaml — no files needed in this folder.

If you DO have custom fonts:
1. Drop the .otf or .ttf files here
2. Register them in styles.css (see the example in that file)
3. Reference them by name in brand.yaml
