# Outlier Swarm — Roadmap

## Shipped

### v1.0 — Member-Ready Release (2026-02-17)

- 5 specialized agents with mutually exclusive mandates
- Mission context integration at 3 touchpoints (opening, agent prompts, report)
- Vault discovery with graceful fallback (Smart Connections → Glob → skip)
- Overlaps of Surprise convergence matrix
- Sacred cow identification and contrarian signal extraction
- Structured report with action verdicts
- Flexible save location (vault → project root → user override)
- Optional daily note linking
- Sub-agents use haiku for cost efficiency

## Future

### Assumption Tracker
- Record which sacred cows the member has tested
- Track which contrarian approaches were adopted vs. dismissed
- Build a profile of "rules you've validated" vs. "rules you've broken"

### Debate Mode
- After the initial swarm, spawn a second round where agents argue with each other
- Mainstream Mapper vs. Contrarian Hunter on specific findings
- Surface the strongest arguments on both sides

### Niche-Specific Agent Prompts
- Over time, refine agent prompts based on what works for specific coaching niches
- A fitness coaching outlier swarm might emphasize different cross-domain connections than a business coaching one
