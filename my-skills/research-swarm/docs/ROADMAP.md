# Research Swarm — Roadmap

## Shipped

### v1.0 — Member-Ready Release (2026-02-17)

- Multi-angle parallel research (3-5 angles via Task tool)
- Mission context integration at 3 touchpoints (opening, angles, report)
- Vault discovery with graceful fallback (Smart Connections → Glob → skip)
- youtube-processor as optional video research angle
- Structured report with contradictions table and action verdicts
- Flexible save location (vault → project root → user override)
- Optional daily note linking
- Sub-agents use haiku for cost efficiency

## Future

### Angle Memory
- Remember which research angles were most useful per topic type
- Over time, the swarm learns what angles yield the best results for your niche

### Research Library
- Index of all past research swarm reports
- "What have I already researched?" command
- Cross-reference findings across multiple swarms

### Depth Control
- Quick mode: 3 angles, summary only
- Standard mode: 3-5 angles, full report (current)
- Deep mode: 5 angles + follow-up sub-agents on promising leads
