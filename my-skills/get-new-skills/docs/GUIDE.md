# Get New Skills - How It Works

## The One-Sentence Version

Say "get new skills" and your Powerhouse installs whatever Ed has released since your last update.

## Why This Exists

First — if you're reading this, good on you. You went looking at the docs. That's exactly the kind of curiosity that gets results with this system.

Here's what's worth understanding: the way you just installed your skills? That's not a one-off setup step. That's the delivery mechanism for everything that comes next.

Every time Ed builds and validates a new skill in the lab, it gets packaged and added to the template repo. When you say "get new skills," your Powerhouse connects to that repo, figures out what's new, installs it, and wires it up. No re-downloading. No setup guides. No waiting for a course module to unlock.

This is a fundamentally different way to deliver training. Instead of watching videos about what a tool could do, you get the actual tool — ready to use, pre-configured with your Mission Context, documented with guides just like this one.

The skill you're reading about right now is what makes that possible.

## How You Use It

Open Claude Code in your Powerhouse folder and say:

```
get new skills
```

That's it. Claude will:

1. Connect to the AI Powerhouse template repo
2. Check what skills you already have
3. Download anything new
4. Register the new skills in your settings
5. Tell you exactly what was installed and how to use it

Your existing skills are never overwritten. Your customisations are safe.

## After Installing

One important step: **open a new terminal session.** New skills only activate when you start fresh.

1. Type `/exit` to close Claude Code
2. Close the terminal window
3. Open a new terminal
4. Navigate to your Powerhouse folder
5. Launch Claude Code

Your new skills are now ready.

## What This Means for You

Think about the training programs you've been through before. You get a login, some videos, maybe a workbook. You watch, you take notes, you try to implement on your own.

This is different. When Ed releases a new skill, you don't watch a tutorial about it. You install it and use it. The skill itself contains the methodology. The docs explain the thinking. Your Mission Context makes it personal.

Every "get new skills" makes your Powerhouse more capable. The same way your phone gets better with each update — except these updates are built specifically for coaches and specifically for you.
