# GHL Social — Guide

## What It Does

Schedules social media posts across your connected platforms — all from Claude Code. GHL does the heavy lifting (actually publishing at the scheduled time). You create the content, approve it, and forget about it.

## Why It Matters

Content that doesn't get published doesn't work. The gap between "I should post this" and actually posting it across multiple platforms is where most content dies. This tool closes that gap.

The compound play: create once, adapt per platform, schedule everything, measure what works, make the next batch better.

## The Three Levels

1. **Publish** — Content plan in, scheduled posts out. One session for the whole week.
2. **Measure** — Pull performance data back. What's actually resonating?
3. **Learn** — Feed data into the next content plan. Each week gets smarter.

## How to Use It

"Schedule the article across LinkedIn and Facebook for Tuesday morning"

That's it. The skill handles content adaptation, dry-run preview, and scheduling.

## What It Doesn't Cover

- X/Twitter (GHL dropped it — $504K/year API cost)
- Medium (not in GHL — separate API)
- Substack (use substack-publisher instead, if installed)
- TikTok (requires mobile app even with GHL)
