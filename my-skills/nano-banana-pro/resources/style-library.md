# Style Library

A growing collection of image generation styles that work well. When you find a prompt style that produces great results, add it here for future reference.

## How to Use This

When generating an image, you can reference styles from this library:
- "Generate an image in the **Cinematic Documentary** style of..."
- "Use the **Bold Headline** style for this hero image"

## Photographic Styles

### Cinematic Documentary
```
Professional documentary-style photograph, natural lighting,
shallow depth of field, candid moment captured, warm color grading
```
**Best for:** Coaching moments, presentations, authentic scenes

### Editorial Portrait
```
Editorial magazine portrait, studio lighting with soft shadows,
clean background, professional retouching, confident expression
```
**Best for:** Headshots, author photos, profile images

### Hero Banner - Warm
```
Wide cinematic shot, golden hour lighting, dramatic sky,
inspiring composition, warm orange and teal color palette
```
**Best for:** Article hero images, landing page headers

## Illustration Styles

### Manga Style (Ed's Brand)
```
Manga illustration style, dynamic composition, expressive character,
clean linework, vibrant colors, dramatic lighting effects
```
**Best for:** Carousel slides, social posts, character-driven content

### Minimalist Concept
```
Clean minimalist illustration, simple shapes, limited color palette,
plenty of white space, single focal point, modern graphic design
```
**Best for:** Thumbnails, icons, concept visualization

### Watercolor Editorial
```
Soft watercolor illustration, loose brushstrokes, muted earth tones,
artistic texture, editorial magazine quality
```
**Best for:** Newsletter headers, gentle/reflective content

## Abstract/Conceptual

### Metaphor Visualization
```
Abstract conceptual art representing [concept], symbolic imagery,
dramatic lighting, artistic composition, thought-provoking visual
```
**Best for:** Abstract concepts (clarity, transformation, growth)

### Bold Headline
```
Bold graphic design with large typography space, high contrast,
modern layout, strong visual hierarchy, social media optimized
```
**Best for:** Quote graphics, announcement images

## Adding New Styles

When you discover a prompt pattern that works great:

1. Give it a memorable name
2. Add the core prompt text in a code block
3. Note what it's "Best for"
4. Optionally add an example image reference
