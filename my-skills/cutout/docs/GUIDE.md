# Create Transparent Assets

**macOS only.** Not supported on Windows.

## Getting Started

Run **"set up cutout"** to install the background removal tools. Takes about 5 minutes.

## What It Does

Creates transparent PNG images — logos without backgrounds, stickers, character cutouts, or any asset that needs transparency.

## Two Modes

**Remove background from an existing image:**
Say "remove background from [image path]" and it strips the background, leaving a clean transparent PNG.

**Generate a new cutout from a prompt:**
Say "create a cutout of [description]" and it generates the image via AI, then removes the background automatically.

## Using Your Reference Photo

If you set up a reference photo during carousel setup, say "create a cutout of me [doing something]" and it uses your photo as reference.

## Common Uses

- Brand logos with transparent backgrounds
- Character stickers for carousel slides
- Product images without backgrounds
- Custom graphics for social media
